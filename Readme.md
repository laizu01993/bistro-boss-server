# 🍽️ Bistro Boss — Backend Server

**Live Server:** [https://bistro-boss-server-5us7.onrender.com](https://bistro-boss-server-5us7.onrender.com)

This is the backend server for the **Bistro Boss** restaurant web application.  
Built with **Node.js**, **Express**, **MongoDB**, **JWT Authentication**, and **Stripe Payment Integration**, it handles all API requests for menu items, users, carts, orders, and payments.

---

## 🚀 Features

### 🔐 Authentication & Authorization
- User registration and login
- JWT-based authentication
- Protected routes for admin and users

### 🛒 User Features
- Fetch menu items by category
- Add, update, and remove items from cart
- Create orders
- View payment history

### 🛠️ Admin Features
- Add, update, and delete menu items
- Manage all users
- View all orders

### 💳 Payment Integration
- Stripe payment gateway
- Secure handling of payment intent and transaction history

---

## 🧩 Technologies Used
- **Node.js + Express**
- **MongoDB**
- **JWT Authentication**
- **Stripe Payments**
- **CORS**
- **Dotenv for environment variables**
- **Nodemon** (for development)
